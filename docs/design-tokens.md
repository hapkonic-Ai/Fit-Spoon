# ChefMate AI — Design Tokens Reference

## Colors
| Token | Value | Usage |
|-------|-------|-------|
| `--color-primary` | `#FF8C42` | CTAs, active states, buttons |
| `--color-primary-light` | `#FFECD2` | Hover states, soft backgrounds |
| `--color-primary-dark` | `#E07030` | Pressed states |
| `--color-secondary` | `#FFD166` | Highlights, accent elements |
| `--color-accent` | `#EF476F` | Emotions, alerts, love |
| `--color-bg` | `#FFF4E6` | Page background |
| `--color-card` | `#FFFFFF` | Card backgrounds |
| `--color-text` | `#3A2D28` | Primary text |
| `--color-text-muted` | `#7A6A64` | Secondary text |
| `--color-border` | `#FFECD2` | Borders, dividers |
| `--color-success` | `#52B788` | Success states |
| `--color-warning` | `#FFB703` | Warnings |
| `--color-error` | `#EF476F` | Errors |
